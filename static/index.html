Checks every 6 hours while this service is running. Either threshold triggers a one-day delay. Existing longer delays are preserved. Forecast failures leave the controller unchanged.

How it works

When rain is on the way, Rainkeeper puts your controller on rain delay. Your existing programs stay on the device, ready for the next dry day.

The Rainkeeper server must stay running and connected to your home network for automatic checks. Forecast rain is an estimate, not an on-site measurement.
